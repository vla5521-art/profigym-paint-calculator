# Этап 2 — итоговая конфигурация

Версия проекта: **1.5.1**

Актуальная конфигурация MVP поддерживает только STEP `.stp` и `.step`.

Реализованы:

- B-Rep импорт через Open Cascade Technology 8 (`occt-wasm`);
- топология Bodies, Shells, Faces, Edges и Vertices;
- площади модели, тел и граней в мм², см² и м²;
- нормализация единиц STEP;
- диагностика поврежденной, пустой, открытой и многотельной геометрии;
- асинхронные задания, API отчетов и frontend-отображение;
- детерминированные face ID для повторного импорта неизмененного файла.

Результаты фактических проверок после STEP-only исправления приведены только в `STAGE2_CORRECTION_REPORT.md`.
