# Проверка Excel-шаблона импорта

Дата проверки: 2026-07-31  
Версия проекта: 1.6.0

## Решение

Файл `public/templates/PROFiGYM_шаблон_импорта.xlsx` нужен приложению и не должен удаляться.

В переданном архиве файл уже присутствовал, поэтому создавать его заново не потребовалось. Он проверен, сохранён в исходной папке проекта и после production build включён в `dist/templates/`.

## Где используется

- `src/components/ExcelImportPanel.tsx` — ссылка «Скачать шаблон Excel».
- `tests/xlsx-archive.test.mjs` — регрессионная проверка точного имени, структуры и production-копии шаблона.
- `scripts/verify-template-packaging.mjs` — обязательная postbuild-проверка имени, XLSX и SHA-256.
- `README.md` — описание формата импорта и расположения шаблона.
- Vite копирует каталог `public/` в `dist/`, поэтому production-версия раздаёт файл по URL `/templates/PROFiGYM_шаблон_импорта.xlsx`.

## Проверка файла

- Формат: корректный Microsoft Excel `.xlsx`.
- Размер: 62 254 байта.
- SHA-256: `0323fb8b03c2a61911104712dc82a4bfc5bf531bf31e67a96f4b99669a9d42e8`.
- Лист: `Материалы`.
- Колонки:
  1. `Производитель`
  2. `Материал`
  3. `Норма расхода, кг/м²`
  4. `Поверхности применения`
- Визуальная проверка: заголовки и пример строки отображаются корректно, ошибок формул нет.
- Исходная и production-копии имеют одинаковый SHA-256.

## Добавленная защита от повторения ошибки

- Тест шаблона проверяет точное UTF-8 имя, отсутствие `PROFiGYM_#U*.xlsx`, ZIP-структуру XLSX, имя листа и четыре точных заголовка.
- Тест выполняет production build и сравнивает SHA-256 файлов в `public/templates/` и `dist/templates/`.
- `npm run build` завершается postbuild-проверкой `npm run verify:template`.
- `npm run smoke:live` проверяет HTTP 200 при скачивании шаблона и побайтовое совпадение с исходным файлом по SHA-256.
