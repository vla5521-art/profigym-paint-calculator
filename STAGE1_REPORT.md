# Этап 1 — рабочий каркас загрузки CAD

Реализованы Express API, безопасное временное хранение, задания со статусами uploaded/processing/completed/failed, единый формат ошибок, логирование, очистка файлов и React-экран загрузки.

Исторический этап загрузки заменён STEP-only реализацией этапа 2. Актуальный MVP принимает только `.stp` и `.step`; список форматов не расширяется переменными окружения.


## Проверка в текущей среде

- Синтаксис всех backend-файлов проверен командой `node --check` — ошибок нет.
- Тесты клиентской валидации: 2/2 пройдены.
- Полный запуск API и сборка не выполнены: внутренний npm registry среды вернул 404 при установке уже существующей зависимости `@types/react`. В обычной среде с доступом к npmjs.org необходимо выполнить `npm install`, затем команды проверки из README.
