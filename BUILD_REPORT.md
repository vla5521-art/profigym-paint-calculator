# PROFiGYM 1.3.1 — отчёт исправления сборки

## Исправленная ошибка

Vercel останавливал сборку с TS2322 в `src/services/xlsxZipReader.ts`: `Uint8Array<ArrayBufferLike>` не соответствовал `BlobPart`.

Исправление: перед созданием Blob входной массив копируется в новый `Uint8Array`, после чего в Blob передаётся гарантированный `ArrayBuffer`.
