# Архитектура 3D viewer

## Поток данных

STEP импортируется на backend через `occt-wasm`. После геометрических расчётов `server/cad/viewer/service.js` вызывает `meshShape()` и получает индексированную сетку с группами исходных B-Rep-граней. Hash группы сопоставляется с тем же `faceId`, который используют расчёт площади, contact detection, feature recognition и таблицы.

Frontend использует Three.js `WebGLRenderer` и `OrbitControls`. STEP/B-Rep не попадает в браузер.

Компонент Viewer загружается через `React.lazy`, поэтому Three.js не входит в основной бандл калькулятора ЛКМ. Снимок формируется из уже отрисованного canvas и проходит серверную проверку перед включением в отчёт.

## Формат

Каждая грань содержит `faceId`, `bodyId`, `positions`, `normals`, `indices`, bounding box, тип поверхности, площадь, категорию, статус и ссылки на features/contacts. Частичный контакт хранится отдельным `patch` mesh с фактической B-Rep-площадью. Поэтому частичный контакт не окрашивает всю исходную грань.

## Управление и доступность

Поддерживаются вращение, панорамирование, масштабирование, изометрия, виды спереди/сверху/справа, сброс, оси и перспективная/ортографическая камеры. Клик возвращает исходный `faceId`; строка таблицы использует тот же ID. Категории имеют цвет, текстовую легенду и описание паттерна. При отсутствии WebGL таблицы, решения, площади и отчёты остаются доступны.

## Лимиты

Значения по умолчанию: linear deflection 0,15 мм, angular deflection 20°, максимум 750 000 треугольников. При превышении сетка до трёх раз огрубляется; если лимит всё ещё превышен, API возвращает контролируемое `VIEWER_MESH_TOO_LARGE`, а расчёт площади остаётся доступен.

## Браузерная проверка

Playwright запускает настоящий Chromium с ANGLE/SwiftShader и проверяет активный `webgl`/`webgl2` context. Raycasting вызывается физическим кликом по canvas; диагностический `cad-viewer-state` сериализует категории и selected-флаг из данных реальных Three.js mesh/material, но не заменяет визуальное выделение. Отдельный контекст с `--disable-webgl` проверяет fallback. Проверяются размеры и отсутствие переполнения на 1440×900, 1024×768 и 768×1024.
