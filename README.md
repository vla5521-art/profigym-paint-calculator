# PROFiGYM — калькулятор расхода краски v1.0.4

Статическая веб-версия калькулятора теоретического расхода лакокрасочных материалов.

## Формула

`Норма расхода (кг/м²) × Площадь окраски (м²) = Общий расход (кг)`

## Файлы

- `index.html` — разметка страницы
- `styles.css` — дизайн и адаптивная верстка
- `script.js` — расчет и проверка введенных данных
- `assets/logo-transparent.png` — логотип без белой подложки
- `assets/paint-booth-bg.jpg` — декоративный фрагмент окрасочного производства

## Локальный запуск

Откройте `index.html` в браузере.

## Публикация на GitHub и Vercel

1. Распакуйте архив.
2. Загрузите содержимое папки в корень GitHub-репозитория.
3. Подключите репозиторий в Vercel.
4. Framework Preset: `Other`.
5. Build Command и Output Directory оставьте пустыми.
6. Нажмите `Deploy`.

Проект не требует сборки и серверной части.
